# 03《MAD之夜》(MAD Night)

由未完成工程 `MAD_TRY.flp` 补全创作的高能量伴奏曲。
原工程只有 29 个 Aqua 语音素材堆在第 0 小节 + 三个空 pattern（140 BPM，无任何音符）。
语音素材无法进入 MIDI，本曲为其编写了**完整的高能量 backing track**，
结构上留出了规整的乐句空间，方便后续把语音采样对位拖入。

- **调性/速度**: A 小调 / 140 BPM
- **结构** (98 小节 ≈ 2:50): 前奏4 → 主歌A 16 → build 4 → 副歌1 16 → 间奏B 8 → build2 4 → 副歌2 16 → 桥段 8 → 终副歌 16 → 尾声 6
- **和声**: 主歌 Am-F-C-G；副歌 F-G-Am-Am / F-G-E7-Am；桥段 F-C-Dm-Am
- **声部** (9 轨): Lead(原创 hook) / Chord Stabs / Warm Pad / Bass(副歌16分泵动) / Arp Pluck / Piano / Bells / Strings / Drums
