# 原创乐曲集 —— 基于"下载"文件夹中的 MIDI 草稿

每个原始 MIDI 文件都据此创作了一首**完整的原创乐曲**：保留原文件的动机/音高素材与气质，
重新设计节奏、曲式（前奏-A-B-再现-尾奏）、和声、配器，并补齐缺失的 MIDI 元信息
（速度、拍号、调号、GM 音色、轨道名）。所有曲子均为 GM 标准格式 1，可直接用任何播放器
（Windows Media Player、DAW、在线 MIDI 播放器）打开。

## 修复的"不合理之处"

**全部文件共同问题**
- 无拍号、无调号、无乐器音色（GM program）→ 全部补齐；
- 音符无力度层次 → 按声部分配力度并做渐强渐弱。

**个别文件问题**
- `New Song.mid`：track0 是 track1 的完全重复（双倍音符）→ 去重，只保留一份 riff；
- `unfinish.mid`：低音 C♯2 与旋律 C4 直接冲突 → 低音改为 A 系；内声部是 C-D-E 这类
  二度音簇（应为和弦被错误记录）→ 改写为规整三和弦；
- `未完成1.mid`：开头 C5+♯F5 小二度音簇、以及高音旋律中间突兀的 ♯C2 低音 → 删除；
- `Track_02.mid`：Fm→Gm→♭A→♭B 的半音和弦链与 A 小调旋律冲突 → 改为
  Am-G-C-G-Am-F-G7-Am 的规整进行；
- `sunny day(.2).mid`、`o.mid`、`New Song2.mid`、`前辈(1).mp3.mid`：**时间轴损坏，
  所有音符的起始时间被压缩在第一拍内**（音符全部堆积重叠）→ 按.note-on 顺序恢复音高
  序列后重新作曲、重新设计节奏；这些文件本身没有可还原的时间信息；
- `前辈(1).mp3.mid`（MP3 转谱）：1388 个音符、音域 E2-G7、大量转谱噪声与八度乱跳 →
  辨认出其和声骨架（F7/E7/D7/A7/G7/C7/B♭ 属和弦链），重写为干净的摇摆布鲁斯；
- `unifish2.mid`：所有音符时长为 0.99 拍（量化误差，造成每拍缝隙）→ 归整到准确网格。

## FL Studio 工程说明

- 每首的 `.flp` 包含全部旋律声部（主音/和声/贝斯/垫底），已按原 GM 音色就近匹配 FLEX 预设；
- **鼓组不在 flp 里**：FL 的 MIDI 导入会把 GM 鼓轨（通道 10）挂到 FLEX 上变成有音高的
  音色（FL 已知行为），故工程文件只含旋律；鼓组在完整 MIDI 的鼓轨中，
  在 FL 里可用 FPC 等鼓机加载（鼓谱见对应 `.mid`），或直接听 `MP3\` 成品；
- 生成方式：`_tools` 已验证的 FL 自动化（导入 → 保存），校验用 FLP 解析器核对音符数。
